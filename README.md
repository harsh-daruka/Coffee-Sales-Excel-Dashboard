# Coffee Sales Dashboard (Excel)

## About the Project

This project is an interactive Excel dashboard built to analyze coffee sales data. It provides insights into sales performance, customer behavior, and country-wise sales using Excel's data analysis features.

## Dataset

The project consists of three datasets:

- Orders
- Customers
- Products

These datasets were cleaned, connected, and used to build an interactive dashboard.

## Features

- Total sales analysis
- Country-wise sales comparison
- Top 5 customers by sales
- Interactive slicers for filtering
- Dynamic charts

## Excel Features Used

- Pivot Tables
- Pivot Charts
- Slicers
- XLOOKUP
- INDEX & MATCH
- IF Statements
- Data Formatting
